# 推荐情绪清单（参考，非强制）

下面这些情绪名只是举例，**不是固定目录**。Soyo 完全可以自创新情绪，1-8 字都可以。这张表只是给一个起点，让你在不确定怎么起名时有个参考方向。

## 高频通用情绪（建议优先收齐 3-5 张）

| 情绪名 | 场景 | 备注 |
|---|---|---|
| 摆烂 | 不想努力了、放弃、随它去 | 比纯"难过"更现代感 |
| 无语了 | 对方说蠢话、被怼的瞬间 | 和 chibi speechless 互补但是带文字图也行 |
| 害 | 失望但承认、轻叹 | 比"难过"轻一些，更日常 |
| 啊这 | 没想到、卡到、当场愣住 | 可以是表情的人 + 一句话那种接话包 |
| 战术后仰 | 难以置信、被刺激到 | 角色/动物歪头看镜头的图最贴 |
| 嘴角上扬 | 坏笑、暗爽、憋笑 | 比"开心"更微妙，含蓄 |

## 群聊互动常用情绪

| 情绪名 | 场景 |

| 喝茶 | 神态轻松、日常、看戏 |

## 反面教材——别用这些名

- `好`、`嗯`、`哦`、`啊`、`行`：太通用，无具体场景
- `开心`：太宽泛，不如拆成 `嘴角上扬` `激动` `被戳中笑点`
- `难过`:太抽象，不如 `心碎` `砸墙` `蹲墙角` 这种更有画面感
- `生气`:同上，细分 `红温` `瞪眼` `咬牙`

## 进阶：组合情绪

8 字以内可以叠情绪让标签更准：

- `无奈且想笑`
- `想了想还是放弃`
- `嘴角压不住`
- `装傻但被识破`

## 反思/筛选自检

收下之前自问三个：

1. **下次同场景我真能直接甩这张吗？** 答"不太确定" → 别收。
2. **这张图自己带不带含义能秒懂？** 答"得过几秒才能解读" → 别收。
3. **是不是已经收过同情绪更好的图了？** 答"是的" → 不收，先 `list(emotion=xxx)` 看看，必要时 `remove` 替换。
